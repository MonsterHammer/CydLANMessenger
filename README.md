# CYD LAN Messenger

CYD LAN Messenger is a modernized fork of the open-source LAN Messenger project.

This project focuses on improving:

* Modern user interface and user experience
* Better chat history handling
* Improved file retention and organization
* Cleaner enterprise/workplace workflow
* Future floating and modern communication features

This project does NOT replace or rewrite the original LAN Messenger networking protocol.
It builds on top of the original project and improves the overall experience while maintaining compatibility goals.

Original LAN Messenger project:
https://github.com/lanmessenger/lanmessenger

Credits to the original LAN Messenger developers and contributors for the networking foundation and core messaging system.
